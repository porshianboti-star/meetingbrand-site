# MeetingBrand — marketing site

This repository is the static source of **[meetingbrand.com](https://meetingbrand.com)**, served by GitHub Pages.

MeetingBrand is a web application that creates branded virtual backgrounds for video meetings from a company's website. An admin signs up with a work email; MeetingBrand fetches the company's public logo and brand colors from that domain, mounts the logo as a physical sign on the wall of a built-in office room, adds an optional name bar with each employee's name and title, and exports every background as a 1920×1080 image that works in Microsoft Teams, Google Meet, Zoom and any other meeting app that accepts custom backgrounds. Delivery is built in for Microsoft Teams (the MeetingBrand Agent, deployed with Intune or Jamf) and for Google Meet (the MeetingBrand Chrome extension); Zoom delivery is coming. Free during early access.

- Website: https://meetingbrand.com
- Documentation (Teams, Google Meet and Zoom delivery): https://meetingbrand.com/docs/
- Room gallery: https://meetingbrand.com/rooms/
- Support: https://meetingbrand.com/support/

## How the site is built

Every page is generated by `gen-site.py`; the HTML files in this repository are its output and are never edited by hand. The product itself (`/app/`) is a separate build that the generator copies in.
